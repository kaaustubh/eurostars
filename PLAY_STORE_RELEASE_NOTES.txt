Release notes (update this file each release):

Release 0.0.1:

New Features:
- Sensoria Sensor Support: Added support for Sensoria D20 and E20 sensor protocols.
- Protocol Detection: Automatic detection of sensor type (Current, Sensoria D20, or Sensoria E20) during pairing.
- Dynamic Data Display: Sensor data display adapts based on sensor type:
  - Current sensors: 18 pressure taxels
  - Sensoria D20: 8 ADC channels
  - Sensoria E20: 6 ADC channels
- Sensor Type Display: Shows detected sensor type in pairing screen details.

Technical Improvements:
- Package refactoring: Migrated from com.sensars.eurostars to com.sensoria.app.
- App rebranding: Changed app name to "Sensoria".
- Sensoria Protocol Parsers: Implemented D20 and E20 protocol parsers with bit-packed data handling.
- Protocol Detector: Automatic protocol detection from GATT services and packet structure.
- Data Handler Integration: Sensoria sensors integrate seamlessly with existing data flow.

Bug Fixes:
- Fixed package import errors across the codebase.
- Resolved compilation errors in navigation and protocol detection.
- Improved BLE scanning to detect all devices (not just UUID-filtered).

Improvements:
- Walking Mode Support for Sensoria Sensors: Walking mode now fully supports Sensoria D20 and E20 sensors. CSV files are generated with correct channel counts (6 for E20, 8 for D20, 18 for CURRENT sensors) and adapt automatically based on connected sensor types.
- Gait Analysis Tab: Limited to session history view only. Navigation to gait analysis detail screen is disabled as the feature is not yet implemented.

Release 0.0.8:

New Features:
- Lateral Center of Mass: New gait metric showing side-to-side body center of mass position.
- Balance Index: New balance metric based on Center of Pressure variability (lower variability = better balance).

Improvements:
- Expanded gait analysis from 5 to 7 metrics for more comprehensive analysis.
- Both new metrics available for clinicians and patients.

Release 0.0.7:

New Features:
- Session gait analysis detail screen for clinician and patient roles (tap a session to open).
- Session CSV v2 includes IMU (accelerometer + gyroscope) alongside pressure.

Improvements:
- Patient gait analysis detail is full-screen (tabs/header hidden) with back navigation.
- Chart indicator stays within the bar; 0 values render at the bar start.
- BLE scanning now detects all devices (removed UUID filtering for broader sensor discovery).
